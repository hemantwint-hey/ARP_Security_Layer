2. Security & Privacy Guarantees Established

  • Zero Raw Identity Ingress to AI: Real customer IDs (customerId, userId, email) can never leave the gateway.
  • Linkage Attack Prevention: Exact rupee amounts and microsecond timestamps are replaced by general bands (MEDIUM_500_2500 and WEEKDAY_NIGHT).
  • Sub-Millisecond Redis Performance: Token lookups run in <1ms via bidirectional Redis keys (arp:map:{customerId} & arp:resolve:{arpToken}).
  • Right-to-be-Forgotten (GDPR Compliance): Invoking revokeAndForget() purges all Redis caches and publishes an arp.identity.revoked tombstone event to Kafka.
